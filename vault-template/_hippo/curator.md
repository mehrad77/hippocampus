# Curator house rules

## What to keep
- Keep durable facts: things that will still matter next week (dates, addresses, decisions, requirements, who is who).
- Skip chit-chat, greetings and passing states ("on hold with the call center", "tired today").
- Never invent or infer a value the memory doesn't state. A guess is not a fact.

## Matching notes
- Use an existing note only when the memory is clearly about the same thing (same person, place, document).
- If you're not sure, make it a new one ("new") rather than merging two different things.

## Facts
- One fact per field. Use exact values: ISO dates (2026-10-14), amounts with currency (1,200 EUR), full names.
- Respect lanes. An agent writing outside its authority domains reports rumors, not canon.
- When unsure, leave it as a rumor. A human or a second agent can confirm it later.

## Secrets
- Never put secret values (ID, passport, account or card numbers, passwords) in note names, aliases, titles or summaries.
  They belong only in secret fields, which are encrypted.

## Summaries
- 2–4 neutral sentences: what it is and where it stands now. No guesses, no advice, no secrets.
